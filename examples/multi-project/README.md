# Multi-Project Skill Hierarchy — Examples

These are example files showing what each level of the skill hierarchy
looks like in practice. Copy and adapt them for your own production.

```
Framework level:  Ships with Cinef (meta.skill.md, git_onboard.skill.md)
Show level:       Your film's global rules (color pipeline, house style)
Scene level:      Continuity between shots in a sequence
Shot level:       What the demo uses now (relight, focus_pull, lipsync)
Variant level:    What we built with cinef:skillVariant (dramatic, subtle)
```

## How to Use These

1. Fork the Cinef repo
2. Create your film project as a separate repo
3. Copy these examples into the appropriate directories
4. Adapt the rules, constraints, and CLAUDE.md files to your production
5. Claude discovers everything automatically by walking the directory tree

See [PRODUCTION_GUIDE.md](../../PRODUCTION_GUIDE.md) for the full folder
structure and migration guide.
